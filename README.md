# RailTransit 轨道交通插件介绍

**RailTransit** 是一款面向 Minecraft 服务器的粘液科技（Slimefun4）附属插件，为服务器提供完整的轨道交通系统：玩家可以自行组织建团、规划铁路线路、编译寻路路径，并让列车沿线路自动驾驶、循环运营。

**插件定位**

- 在服务器中搭建可运营的城市轨道交通（地铁/单轨/环线）系统
- 面向多玩家协作：以"组织"为单位管理线路，成员共同建设和运营
- 以原版铁轨为轨道基础，配合 Slimefun 物品与 GUI 完成全流程操作

---

**核心特性**

- **组织管理**：玩家可以成立组织、设置组织名称与头像、邀请成员加入，以组织为单位运营铁路
- **线路系统**：组织内可创建多条线路，每条线路绑定一组站台，支持设置是否回厂、发车间隔、站停时长
- **智能编译寻路**：右键侧线铁轨作为起点，插件使用 DFS 算法沿铁轨自动寻路，途经所有目标站台并生成路径关键点；路径可持久化保存
- **断点续编**：编译途中遇到未加载区块时，移动到目标位置后输入 `/railtransfer continue` 即可原地继续，无需返回起点
- **列车自动驾驶**：放置列车后自动沿编译路径循环运行，到站自动报站并停留，完成一圈后在回车厂等待后再次发车
- **服务器重启恢复**：重启后自动扫描并恢复线路上运行的列车，无需重新发车
- **全 GUI 操作**：指挥台提供可视化控制台，组织、线路、站台、编译等操作均可点击完成

---

**运行环境**

- Minecraft 服务端：Paper 26.2
- 前置插件：Slimefun4（粘液科技，需支持当前 MC 版本）
- 插件版本：v1.0.2
- 作者：yxy317coder

**安装方法**

1. 将 Slimefun 插件与 `RailTransit v1.0.2.jar` 放入服务器 `plugins` 目录
2. 重启服务器
3. 插件会自动生成配置文件（`group.json`、`station.json`、`config.yml`）

---

**新增物品**

- **列车（RT_TRAIN）**
  - 外观：矿车
  - 获取：增强工作台合成，配方为动力矿车
  - 用途：放置在已编译线路的侧线铁轨上，接入线路自动驾驶
- **指挥台（RT_CONTROLLER）**
  - 外观：讲台
  - 获取：增强工作台合成，配方需要铜线、红石块、基础电路板等
  - 用途：右键打开轨道交通控制台，管理组织、规划铁路、编辑线路

**轨道系统**

RailTransit 使用原版铁轨作为轨道基础，按材质区分为四种角色：

- **普通铁轨**（RAIL）：普通路段
- **高速铁轨**（动力铁轨 POWERED_RAIL）：高速路段
- **站停铁轨**（激活铁轨 ACTIVATOR_RAIL）：站台所在位置，列车到站停留
- **侧线铁轨**（探测铁轨 DETECTOR_RAIL）：线路起点与回车厂，用于编译起点和发车

---

**组织系统**

- 组织信息保存在 `group.json`，包含名称、图标（自定义头颅）、创建者、介绍、成员列表
- 通过指挥台控制台可以：查看组织、成立组织、管理组织
- 只有加入组织的玩家才能为组织创建和编辑线路

**线路系统**

- 线路信息保存在 `station.json`，一条线路包含：所属组织、线路编号、线路名称、经过站台列表、是否回厂、回车厂后再次发车秒数、每站停留秒数、编译路径
- 线路支持两种运行模式：
  - **单行线（回厂开启）**：侧线 → 站台按序 → 返回侧线（回车厂）
  - **环线（回厂关闭）**：侧线 → 站台按序 → 回到第一站，循环运行
- 站台列表变更后需要重新编译线路

---

**指令列表**

- `/railtransfer select [组织id] [线路id]`：选中线路，之后放置列车即可按该线路运行
- `/railtransfer compile [组织id] [线路id]`：编译线路，随后空手右键侧线铁轨作为起点
- `/railtransfer continue [组织id] [线路id]`：继续编译，可省略参数使用最近一次编译的线路
- `/railtransfer out [组织id] [线路id]`：设置回车厂后再次发车时间（秒）
- `/railtransfer wait [组织id] [线路id]`：设置每站停留时间（秒）
- `/railtransfer help`：查看帮助
- `/railtransit`：主命令入口，`rt`、`railway`等皆可

**权限节点**

- `railtransit.use`：使用轨道交通指令的权限

---

**数据存储**

- `plugins/RailTransit/group.json`：组织数据
- `plugins/RailTransit/station.json`：站台与线路数据（含编译路径）
- 编译路径中的关键点包括：起点侧线、拐角、每个站台位置、终点侧线
- 列车绑定线路信息存储在矿车实体的 PersistentDataContainer 中，用于重启恢复
